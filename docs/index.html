Pinplank: Screw Puzzle

A relaxing screw pin puzzle. Unscrew the pins that have no plank on top, drop each screw into the box of its colour, and watch the planks fall away. Every level is dealt so it can be solved, and you only lose when you are really stuck. Free, plays offline, no account.

Features

  • Every board is dealt along an order where each screw is free when taken and the colour boxes arrive in that order, so every level can be cleared.
  • Full holding holes never end a level early: it ends only when no free screw fits an open box, and an extra hole keeps you going.
  • Planks drop off the board when their last screw is out; levels grow to six-layer stacks.
  • Every screw head has its own shape mark, so colour-blind players can match by shape.
  • First undo every level is free; hints and extra holes when you need them; a Daily Board for everyone.
  • No ads during a level, no banners; videos for coins or an extra hole are always your choice.
